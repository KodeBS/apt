KodeBS APT repository

Debian packages for KodeBS software · amd64 · Ubuntu 22.04 and later.

Set up, once

Trust the signing key and add the repository:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://kodebs.github.io/apt/kodebs.asc | sudo tee /etc/apt/keyrings/kodebs.asc > /dev/null

sudo tee /etc/apt/sources.list.d/kodebs.sources > /dev/null <<'EOF'
Types: deb
URIs: https://kodebs.github.io/apt
Suites: stable
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/kodebs.asc
EOF

sudo apt update

kodebs-server-manager0.0.5-1A lightweight Ubuntu desktop application for managing local servers and developer tooling

Install any of them by name:

sudo apt install kodebs-server-manager

Update and remove

Updates arrive with everything else on the machine:

sudo apt upgrade
sudo apt remove <package>

# to drop the repository itself
sudo rm /etc/apt/sources.list.d/kodebs.sources /etc/apt/keyrings/kodebs.asc
